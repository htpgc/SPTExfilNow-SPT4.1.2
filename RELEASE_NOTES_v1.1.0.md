# SPTExfilNow 1.1.0 - SPT 4.1.2

Compatibility adaptation of the original **SPTExfilNow** by **ragnaroks**.

## Changes

- Updated for SPT 4.1.2
- PMC extraction supported
- Scav extraction supported
- Normal raid settlement preserved
- Loot persistence verified
- Quest item persistence verified
- Quest progress verified
- Experience settlement verified

## Behavioral difference

The original version randomly selects one active extraction point.  
This adaptation uses the first active extraction point returned by the game.

This only affects the extraction point name used for settlement and does not affect immediate extraction or normal post-raid saving.
